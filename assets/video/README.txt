Drop your own car-wash / detailing footage here as:

    wash.mp4   (H.264 MP4, 1920x1080 or 1280x720, 10-25s, no audio needed)

Every page with a .media band picks it up automatically. Until the file
exists the band shows the poster photograph instead, so nothing breaks.

Keep it under ~8 MB so the page stays fast. Handbrake preset
"Fast 1080p30" with audio removed is a good starting point.
